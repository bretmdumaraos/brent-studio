# Brent Studio — GitHub Pages Website

A static website built from the provided Brent Studio logo, banner, screenshots and HTML documents.

## Publish to GitHub Pages

1. Create a public repository called `brent-studio` in your GitHub account `bretmdumaraos`.
2. **Extract the ZIP file.** Upload the actual files and the complete `assets/` folder to the **repository root**. Do not upload the ZIP as the website.
3. The repository root must contain `index.html`, `guide.html`, `privacy.html`, `terms.html`, `404.html` and `assets/`.
4. Commit the files to `main`. Go to **Settings → Pages → Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Check **Actions** until Pages deployment succeeds. Website URL: `https://bretmdumaraos.github.io/brent-studio/` (if repository is named `brent-studio`).
6. Use `Ctrl+Shift+R` or a private browser window after deployment if you see an older version.
